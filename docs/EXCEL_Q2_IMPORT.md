# Как открыть план Q2 в Excel

## Файлы

| Файл | Назначение |
|------|------------|
| `CLIMBA_Q2_2026_EXCEL_PLAN.csv` | **96 строк** — все активности по неделям (0–13) |
| `CLIMBA_Q2_2026_METRICS.csv` | **13 недель** — только цифры (удобно заполнять факт) |

## Импорт

1. Excel → **Данные** → **Из текста/CSV** (или двойной клик по файлу).
2. Кодировка: **UTF-8**.
3. Разделитель: **точка с запятой (;)**.
4. Колонки **«KPI факт»**, **«Бюджет факт ₽»**, **«Статус»** — заполняешь по ходу.

## Этапы Q2

| Этап | Недели | Смысл |
|------|--------|--------|
| 1 Подготовка | 0 | QR, стенд, договор, аналитика |
| 2 Запуск / Пилот | 1–4 | Launch, лига, ~1 месяц техэтапа |
| 3 Удержание | 5–12 | Контент, WAC, кейс для B2B |
| 4 Итоги Q2 | 13 | Сводка, оплата, план Q3 |

## Цели квартала (план)

- Установки: **≥100**
- Активация: **≥45%**
- D7: **≥25–30%**
- D30: **≥12–15%**
- WAC к неделе 8: **≥25–35**
- Бюджет: **≤30 000 ₽**

Зал: **«Луч»**, Крестовский, боулдеринг.
