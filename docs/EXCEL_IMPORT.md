# Маркетинговый план Excel — для показа маркетологу

## Файл

**`CLIMBA_MARKETING_PLAN_2026_2027.xlsx`**

Путь: `Desktop/climba-lending-2/docs/`  
Открыть: **двойной клик** (Excel / Numbers). Git push не нужен.

## 12 листов — что внутри

| № | Лист | Содержание |
|---|------|------------|
| 1 | **Резюме** | One-pager: продукт, North Star, KPI года, бюджет, ЛПР «Луч» |
| 2 | **Стратегия** | ЦА B2C/B2B, УТП, конкуренты, воронки, что не обещать |
| 3 | **Gantt (52 нед)** | Цветной план-график июнь 2026 — май 2027 (как шаблон) |
| 4 | **Бюджет** | Q2–Q4 по статьям, performance vs brand |
| 5 | **KPI недели** | 52 недели с **планом** + пустые колонки **факт** |
| 6 | **B2B воронка** | CRM-этапы, «Луч», 2-й зал, МСК |
| 7 | **Контент-календарь** | Темы по месяцам, TG/Reels/офлайн |
| 8 | **Каналы** | Матрица да/нет/приоритет Q2–Q4 |
| 9 | **Ивенты** | Launch, турнир, лига, Q3/Q4 ивенты |
| 10 | **Риски** | Реестр + действия |
| 11 | **Глоссарий KPI** | WAC, D7, D30, MRR — для маркетолога |
| 12 | **Детальный план** | Задачи по неделям + колонки факт/статус |

## Что заполняет маркетолог / ты по ходу

- Лист **5 KPI** — колонки «Факт уст», «Факт WAC», «Комментарий»
- Лист **4 Бюджет** — «Факт ₽»
- Лист **6 B2B** — «Факт / дата», статусы сделок
- Лист **12 Детальный** — «KPI факт», «Бюджет факт», «Статус»

Всё остальное уже заполнено как **рабочий план**.
